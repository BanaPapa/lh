### 7-1. 제2종 근린생활시설·운동시설 판별을 어떻게 할 것인가

| | |
|---|---|
| **무엇이 문제인가** | 다목은 **「제2종 근린생활시설과 운동시설에 해당하는 것은 제외」** 다. **AND 조건이 두 겹**이다. 그런데 전달받은 `29_34_building_register.xlsx` 에는 건축물 용도 필드가 없다 |
| **보고와 실물의 차이** | LH 회신문 §5는 「건축물대장 용도 조회 **2,730건**과 교차확인」이라 보고했으나 파일은 **337건**(그중 테마파크 89건)이다 |
| **원장 용도 컬럼 확인 결과** | `BLDG_USG_NM` 값을 세어 보니 **영업 119건 중 81%(96건)가 빈칸**이다. **확정 제외 가능은 「체육시설」 1건뿐**이고, **근린생활시설 15건은 제2종 여부 추가 확인 대상**이다(§6-1) |
| **결정하면 달라지는 것** | ① 원장 용도만으로는 **확정 제외 1건 + 추가 확인 15건**이고 나머지 103건은 판별 불가다 ② 건축물대장을 확보하면 전건 판별 가능 ③ 확보 불가 시 **「검토 필요」 상한** |
| **남은 것** | ① **근린생활시설 15건·체육시설 1건은 즉시 제외 적용 가능** ② 나머지 102건은 건축물대장 용도·연면적 확보 필요 ③ 그래도 불가하면 LH에 처리 방침 질의 |

### 7-1. 환경부 계열에 위치자료를 요청할 것인가

| | |
|---|---|
| **무엇이 문제인가** | 전북 유독물 취급시설 위치자료를 찾지 못했다. LH 검토 자료는 **「일부 지역만 정보 공개」** 라 했으므로 **지역별로 공개 수준이 다르다** |
| **어디에 요청하나** | 마목은 **화학물질관리법** 소관이라 **환경부·화학물질안전원·전북지방환경청** 계열이다. 다목(소방서)·자목(경찰서)과 경로가 다르다 |
| **LH 방침** | 08-20 최기헌 팀장님 — *"공장과 위험시설은 **전북에서 최대한 찾아보고 적용**하면 되고"* |
| **비슷한 선례** | 자목(화약류)의 [요청 4]에 **수행팀이** 「달리 활용 가능한 위치 자료(관할 경찰서 협조 등)」 문구를 넣어 보냈고 LH가 「승인」으로 회신했다(문구는 수행팀 요청문 — 09-02 정정). **같은 접근이 가능하다** |
| **결정하면 달라지는 것** | 확보 성공 시 마목이 「판정 적용」으로 바뀌고 **미확보 6개 목 중 하나가 닫힌다** |
| **주의** | 확보하더라도 **LH 보고 정정이 필요하다.** [요청 2] 승인 범위를 벗어나는 변경이다 |
| **협의 상대** | **수행팀 → LH** (협조 요청) |

> **다목·마목·자목 세 항목이 같은 성격이다** — 「자료가 없다」가 아니라 「관할 기관별 공개 정책 차이」다. **세 건을 묶어 한 번에 협조 요청하는 것이 효율적이다.**

## 10. 한 줄 결론

**LH 판정 방침은 확정됐고([요청 2] 승인), 남은 것은 자료 확보 노력이다.**

박진주 대표님이 08-18에 *"LOCALDATA에서 취합이 안 되고 소방청·행안부 자료에서도 못 찾았다"* 며 가장 먼저 제기했고, 그대로 「판정 미적용」으로 확정됐다.

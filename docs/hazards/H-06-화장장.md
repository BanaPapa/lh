| **어느 쪽이 맞나** | **원본 도로명주소(콩쥐팥쥐로 1705-138)가 맞다.** 카카오 키워드 검색으로 「전주시승화원」을 찾으면 효자동3가 산 170-1이 나오고 도로명 좌표와 24m 일치한다(§6-3) |
| **왜 위험한가** | **500m 기준 항목**이다. 1.9km 틀리면 실제 500m 안의 사업지를 놓치고, 엉뚱한 곳을 잡는다. **전주는 검증 표본 17건 중 9건이 있는 지역**이다 |
| **현재 상태** | 박진주 대표님이 09-01에 「화장장 좌표 보완 → 완료」로 회신했으나, **어떤 좌표를 썼는지 확인되지 않았다.** 국장님 좌표를 썼다면 틀린 상태다 |
| **남은 것** | ① 박진주 대표님 차기판에서 전주시승화원 좌표 확인 ② 국장님께 「효자동3가 3 ↔ 산 170-1」 차이 공유 ③ **원본 도로명주소 기반 값으로 통일** |
| **협의 상대** | **수행팀** — LH 질의 대상이 아니다 |

> **이 항목의 유일한 실질 미결이며, 즉시 조치가 필요하다.**

### 7-2. 봉안시설·자연장지를 포함할 것인가

| | |
|---|---|
| **무엇이 문제인가** | 기준은 **「화장장」** 이고 원본 자료는 화장로를 갖춘 시설만 수록한다. 봉안시설(납골당)·자연장지·묘지는 들어 있지 않다 |
| **지금까지 확인된 것** | LH 회신·회의록에 봉안시설 언급이 없다. 심사표 체크박스도 「군부대 사격장, **화장장**」으로만 적혀 있다 |
| **왜 문제가 적은가** | 문언이 「화장장」으로 명확하고, LH가 지정한 원천(보건복지부 전국 화장시설 현황)도 화장시설만 담는다. **확장 해석의 근거가 없다** |
| **결정하면 달라지는 것** | 포함한다면 전북 봉안시설·공원묘지가 대거 추가된다. 다만 **현재로서는 포함할 근거가 없다** |
| **협의 상대** | **수행팀 → LH** (확인 성격, 우선순위 낮음) |

다만 **API 응답에 좌표가 없을 수 있으므로**(전북 자료가 그랬다) 확장 시에도 지오코딩이 필요하다.

## 10. 한 줄 결론

**기준은 매입제외 항목 중 가장 단순한데(500m · 교차조건 없음 · 유형분기 없음 · 5건), 좌표 하나가 1.9km 틀렸다.**

조준환 국장님이 진용성 대표님 B-3에 답하며 제공한 전주시승화원 좌표가 **「효자동3가 3」** 인데, 실제 승화원은 **「효자동3가 산 170-1」** 이다. **「산」 표기가 빠졌다.** 500m 기준에서 1.9km 오차는 판정을 완전히 뒤집는다.

**박진주 대표님이 09-01에 「화장장 좌표 보완 완료」로 회신했으므로, 차기판에서 이 좌표가 어느 값인지 즉시 확인해야 한다.** 전주는 검증 표본 17건 중 9건이 있는 지역이다.

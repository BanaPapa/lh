| **어떻게 읽을 수 있나** | ① **문언대로** — 제조는 바목이 아니다. 저장소·판매만 대상(**280건**) ② **라목으로** — 라목은 「액화가스 취급소·판매소」인데 「취급소」에 제조가 들어갈 수 있다 ③ **전건 대상** — 고압가스업 등록시설이면 목 구분 없이 50m |
| **현재 처리 — 09-02 정정** | ~~전건 적재·③번~~ → **조준환 국장님 엔진은 이미 ①에 가까운 필터를 돌리고 있다.** `_hazmat_kind()` — 제조구분 **냉동 → 판정 미적용(365건)** · **저장·판매 → 확정 판정 대상(286건)** · 그 외(제조 일반·충전·미기재) → **확정 금지 REVIEW(159건)**. §7-1에 인용한 국장님 08-31 발언(「냉동 365·저장/판매 286·충전 81」)과 정확히 일치한다. **다만 이 필터는 LH 서면 승인이 없는 수행팀 자체 처리**이므로 §7-2의 질의 자체는 유효하다 |
| **결정하면 달라지는 것** | ①번이면 영업 중 대상이 794 → **280건**(저장소 208 + 판매 72)으로 줄어든다. §7-1(냉동 제외)과 겹치는 부분이 있어 함께 정해야 한다 |
| **협의 상대** | **LH** — 목 배정 문제 |

### 7-3. 특정고압가스 462건은 어느 목인가

| | |
|---|---|
| **무엇이 문제인가** | `18_20_specific_high_pressure_gas.xlsx` 462건이 **체크리스트에 행이 없는데 LH 보고에는 합산**돼 있다. 회신문 §4 라목의 「고압가스업 1,773건」이 `1,311 + 462` 다 |

| **왜 중요한가** | 사용신고 시설은 **가스를 쓰는 곳**이지 저장·판매하는 곳이 아니다. 제2호 공통 전제(설치·**영업 허가** 대상 건축물)에 해당하지 않을 수 있다. §7-1의 자가용 설비 문제와 같은 성격이다 |

| **남은 것** | 수행팀이 먼저 자료 성격을 확인하고, 대상이라면 어느 목인지 LH에 질의한다. **LH 보고에 이미 합산돼 있으므로 빼려면 정정 보고가 필요하다** |
| **협의 상대** | **수행팀 → LH** |

## 8. 전국 API 자료

> **이 MVP는 전북 데이터만 맞으면 된다.** API는 판정에 쓰는 것이 아니라 **같은 방식을 전국으로 넓힐 수 있는지 판단하는 용도**다.

| API | 대상 | 원본 자료와의 관계 | 전국 확대 |
|---|---|---|---|
| `apis.data.go.kr/1741000/city_gas_companies/info` | 일반도시가스업 | **같은 자료** — `17_…xlsx`의 전국판 | ✅ 가능 |
| `apis.data.go.kr/1741000/high_pressure_gas/info` | 고압가스업 | **같은 자료** — `18_20_high_pressure_gas.xlsx`의 전국판 | ✅ 가능 |
| (특정고압가스 API) | 특정고압가스 | 체크리스트에 행이 없어 미확인 | ⚠️ §7-3 |
| **없음** | LNG 전용 시설 | 자료 자체를 찾지 못했다 | ❌ 미확보 |

**→ 전국 확대 판단:** 라·바목의 두 축(일반도시가스업·고압가스업)이 **전국 API로 그대로 제공된다.** 서울 확장 시 별도 자료 확보가 필요 없다.
다만 **자가설비·업태 필터(§7-1·§7-2)는 전국으로 갈수록 영향이 커진다** — 서울은 대형 건물이 많아 건물 냉방용 냉동기 비중이 전북보다 높을 것이다.

## 10. 한 줄 결론

**자료는 가장 튼튼한데 필터가 가장 불확실한 항목이다.** 좌표 품질이 검증한 자료 중 최고(100m 이내 72%)이고 전국 API도 두 축 모두 있다. 그런데 **원장 1,311건 중 무엇이 판정 대상인지가 정해지지 않았다.**

**영업 중 794건에서 자가용 냉동설비 360건(45%)을 빼야 하는지(§7-1), 「제조」 업태 514건(65%)을 빼야 하는지(§7-2)가 미결이다.** 둘 다 빼면 대상이 100건대로 줄어든다. **전주우체국·소방서·교회가 유해시설로 잡히는 현재 상태는 제2호 공통 전제에 어긋난다.**

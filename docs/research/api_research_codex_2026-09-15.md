**공개 API 연결 가능성과 LH 심사요건 충족 여부는 별개다.** 시설 위치를 조회할 수 있어도 공장 여부, 특정 유해물질, 소음도 예외, 출입구·정문 위치가 없으면 해당 판정을 완성할 수 없다.

조사는 공공데이터포털·기관 문서·공개 샘플을 기준으로 했다. 인증된 실제 데이터 호출은 검증하지 못했다. 일부 Swagger·ODcloud 명세는 접근되지 않아, 기존 브리프·저장소에서 확인한 주소는 **「미검증」**으로 표시했다. `401/403`이 활용신청 대기 때문이라는 기존 상태도 이번에 재현하지 않았다.

**공통 인증·연계 사항**

- **공공데이터포털 일반 API:** 로그인 → 해당 데이터 상세 → `활용신청` → 활용목적 입력 → 마이페이지의 활용신청 현황에서 승인·이용기간 확인 → 인증키 사용. 아래에서 자동승인이라고 적은 서비스도 실제 키 반영 시간을 보장하는 문서는 확인되지 않았다.
- **ODcloud 자동변환 API:** 파일데이터 상세의 `Open API`·`활용신청`으로 이동한다. 파일 다운로드 버튼과 API는 다르며, 버전별 UDDI를 확인해야 한다. 승인 방식·일일 한도는 해당 신청 화면 기준으로 확인해야 한다.
- **기관 LINK API:** data.go.kr에 등재되어 있어도 기관 자체 회원가입·별도 키가 필요할 수 있다.
- 아래 호출 예시의 `KEY`는 실제 발급 키로 대체한다. 인증키를 이중 URL 인코딩하지 않는다.
- 문서가 좌표를 위도·경도로만 설명한 경우 EPSG 번호까지 확인됐다고 쓰지 않았다.
- **LOCALDATA는 2026년 공공데이터포털로 통합 이관되었다.** 공식 안내에는 209종 API 제공과 기존 사이트의 2026-04-15까지 병행 운영이 명시되어 있다. 따라서 과거 `localdata.go.kr`의 변경분 API·인증 절차를 신규 연계의 기본값으로 삼으면 안 된다. [공식 이관 안내](https://www.aigov.go.kr/promotion/notice/64)

**1. 소음진동배출시설 공장 — C, 시설 위치 수집은 B**

**원천:** 지방자치단체 제공, 전국소음진동배출시설표준데이터 `15139233`. 연간 정비 후 통합 데이터가 갱신되는 구조다. 조회 페이지에는 46개 제공기관 등록이 표시되어 있어, 제목의 “전국”만으로 전국 모든 시설의 완전성을 보장할 수 없다. [공식 데이터·명세](https://www.data.go.kr/data/15139233/standard.do)

**엔드포인트·호출 예시**

```text
https://api.data.go.kr/openapi/tn_pubr_public_noise_vibration_emission_fclt_api?serviceKey=KEY&pageNo=1&numOfRows=100&type=json
```

- 인증 필수: `serviceKey`.
- 조회 제어: `pageNo`, `numOfRows` — 최대 1,000, `type=xml|json`.
- 선택 검색: `FCLT_NM`, `CTPV_NM`, `SGG_NM`, `LCTN_ROAD_NM_ADDR`, `LCTN_LOTNO_ADDR`, `NOIS_VBRT_SE_NM`, `DATA_CRTR_YMD`, `instt_code` 등.
- 공개 표에는 일부 변수의 필수·선택 구분이 없으므로 예시처럼 페이지·형식을 명시하는 편이 안전하다.

**응답·공간정보**

| 구분 | 필드·확인 결과 |
|---|---|
| 시설명 | `FCLT_NM` |
| 주소 | `LCTN_ROAD_NM_ADDR`, `LCTN_LOTNO_ADDR` |
| 위치 | `LAT`, `LOT`; EPSG 번호는 명시 확인 못함 |
| 유형 | `NOIS_VBRT_SE_NM`, `NOIS_VBRT_MAIN_CN` |
| 지역 구분 | `GNRL_RGN_YN`, `RDSD_RGN_YN` |
| 기준일 | `DATA_CRTR_YMD` |
| 부족한 필드 | 공장 여부, 영업·폐쇄 상태, 측정 소음도, 방음시설·예외 인정 여부 |

**인증:** 해당 표준데이터 → 활용신청. 일반 서비스키, 개발·운영 자동승인, 개발계정 일 10,000회. 승인 반영 소요는 미확인.

**판단:** 자동차정비업소도 포함되므로 모든 행을 “소음진동배출 공장”으로 처리하면 과포함이다. 소음도·방음시설 필드가 없어 50dB 예외도 판정할 수 없다.

**확보 순서**

1. API에서 위치 후보를 수집하고 기존 공장등록 필지정보와 주소·필지 단위로 대조한다.
2. 관할 환경부서에 공장 해당 여부, 배출시설 허가·신고 상태, 소음 측정 결과의 공개 API 제공을 요청한다.
3. 예외 판정은 측정 조건·측정 지점·시점까지 확인되는 자료로 처리한다. API 확보 전에는 예외를 자동 인정하지 않고 검토 대상으로 남긴다.

**2. LPG 판매소 — C**

**원천:** 한국가스안전공사 LPG 판매업소 현황 `15091481`. 확인된 자료는 **2024-03-05 기준, 4,542행, 일회성**이다. 최신 페이지 수정일과 데이터 기준일을 혼동하면 안 된다. [공식 데이터](https://www.data.go.kr/data/15091481/fileData.do)

**ODcloud 호출 후보 — 현행 UDDI 미검증**

```text
https://api.odcloud.kr/api/15091481/v1/uddi:f40c83ef-d9dd-49b7-a912-bfbdfad65118?page=1&perPage=100&serviceKey=KEY&returnType=JSON
```

위 UDDI는 기존 조사 자료에 있는 주소이며, 이번에 현행 Swagger·정상 응답으로 재확인하지 못했다.

- 인증: `serviceKey`.
- 조회: `page`, `perPage`.
- 형식: `returnType=JSON` 사용 여부는 현행 명세에서 재확인 필요.
- 시설명·주소 조건검색 파라미터는 확인하지 못했다.

**응답:** 공개 데이터 열은 `일련번호`, `업소명`, `주소`. 좌표·시설 상태·행별 기준일 없음. EPSG 해당 없음. API 응답의 실제 외곽 구조는 미검증이다.

**인증:** `15091481` 상세 → Open API → 활용신청 → 마이페이지 승인 상태 확인. ODcloud 서비스키 사용. 자동승인 여부·승인 소요·일일 한도는 공개 화면에서 확정하지 못했다.

**판단:** 주소 지오코딩은 가능하지만 2024년 명부만으로 현재 영업 중인 판매소를 확정할 수 없다. **LOCALDATA의 LPG 판매업 전용 현행 API·슬러그는 확인하지 못했다.** 고압가스 판매업이나 LPG 충전업으로 대체하면 안 된다.

**확보 순서**

1. KGS에 동일 데이터의 최신 버전·정기 갱신·폐업 반영 여부를 문의한다.
2. KGS 또는 시군구 LPG 판매사업 허가부서에 허가번호·주소·상태·변경일을 포함하는 API 제공을 요청한다.
3. 지역별 허가 API를 확보한 지역부터 통합한다. 2024년 자료는 과거 후보 탐색용으로만 사용한다.

**3. LPG 저장소 — C**

**원천:** KGS 가스시설 현황 `15067840`은 지역·시설종류별 현황을 제공하지만 전국 개별 저장소의 위치 원장으로 확인되지 않았다. 브리프의 소형저장탱크 `15020467` 역시 개수 자료를 개별 허가 저장소로 대체할 수 없다. [KGS 공식 데이터](https://www.data.go.kr/data/15067840/fileData.do)

지역 후보로 `15052478`의 북부소방서 관내 가스시설 현황이 검색되었다. LPG 저장·판매·충전 등 여러 시설이 섞인 지역 자료이며 전국 원장이 아니다. [지역 가스시설 자료](https://www.data.go.kr/data/15052478/fileData.do)

**엔드포인트·파라미터**

- 목적에 맞는 **전국 시설별 API 엔드포인트는 미확인**.
- 지역 자료는 파일·자동변환 API 후보지만 정확한 UDDI와 요청 스키마를 확인하지 못했다.
- 따라서 실행 가능한 전국 호출 URL을 제시할 수 없다.

**필드:** 전국 집계는 지역·시설 구분·시설 수 중심. 개별 주소·위경도·영업 상태 없음. 지역 후보의 상세 주소·좌표·상태 스키마는 미검증. 전국 시설별 갱신주기도 미확인.

**인증:** 개별 저장소 API가 확인되지 않아 적용할 승인·쿼터가 없다. 지역 ODcloud 후보는 별도 활용신청·버전 확인이 필요하다.

**확보 순서**

1. KGS 검사 DB에서 **허가 대상 LPG 저장소**만 추출한 시설별 공개 API 제공을 요청한다.
2. 시군구 가스사업 허가부서의 저장소 설치허가 자료를 API로 묶는다.
3. 요구 필드는 허가번호, 시설 종류, 실제 설치 주소, 저장능력, 상태, 변경일이다.

소형저장탱크가 있는 모든 사용시설을 법정 저장소로 취급하거나, LPG를 제외하는 고압가스 저장소 자료를 대신 쓰면 안 된다.

**8. 화약류 저장소 — D**

**원천 조사:** 경찰의 통계·허가 행정자료는 존재하지만 전국 저장소의 시설별 주소·좌표 공개 API를 확인하지 못했다. 총포화약안전기술협회 관련 검색에서도 전국 위치 API 명세를 확보하지 못했다. 경찰 행정규칙에는 관련 허가 관리 체계가 나타난다. [경찰 관련 행정규칙](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000261338)

**엔드포인트·파라미터·응답:** 목적에 맞는 공개 API 미확인. 따라서 실행 URL, 필수·선택 변수, 주소·좌표·상태·기준일 필드를 제시할 수 없다. 시설 수 통계는 위치 판정에 사용할 수 없다.

**인증:** 공개 API가 확인되지 않아 키·승인 소요·호출 한도 해당 없음.

**확보 순서**

1. 경찰청 및 시도경찰청의 화약류 저장소 설치허가 담당부서에 공개 API 제공을 신청한다.
2. 전국 일괄 공개가 어려우면 사업지 좌표·반경을 입력하고 저장소 존재 여부를 반환하는 제한형 조회 방식의 제공 가능성을 문의한다.
3. 기술협회에는 시설 유형 해석·검사자료 보유 범위를 문의하되 경찰 허가원장과 동일하다고 간주하지 않는다.
4. API 확보 전에는 브리프의 LH 승인 수기 절차를 유지한다.

공개 제한 여부는 기관 답변 없이 단정하지 않는다. 요청 필드는 허가번호, 실제 저장소 주소, 종류, 운영·폐지 상태, 기준일이다.

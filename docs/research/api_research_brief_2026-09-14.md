# 미연결 원천 전국 API 조사 브리프 (2026-09-13)

목적: LH 매입제외 유해요소 판정 앱(lh_mvp)에서 현재 API 로 연결되지 않은 항목에 대해,
전국 단위로 시설별 주소·좌표(또는 주소 지오코딩 가능)를 제공하는 공개 API 를 찾는다.
로컬 납품 파일(박진주 데이터셋)은 대체 후보로 치지 않는다.

각 항목에 대해 보고할 것:
- 원천명 · 제공기관 · 포털 URL(data.go.kr / odcloud / 기관 자체 API) · API 엔드포인트
- 제공 형식(REST/OpenAPI, 파일+API, 파일만, 웹게시만)
- 필드: 주소 유무, 위경도 유무, 좌표계, 시설유형 구분 필드, 영업상태, 기준일, 갱신주기
- 전국 커버리지 여부(지역 한정이면 명시)
- 인증 방식(data.go.kr 일반키 / odcloud 서비스키 / 기관 자체 신청)
- 판단: A 즉시 연결 가능 / B 활용신청·인증 필요 / C 자료는 있으나 판정에 부족(좌표 없음·집계만) / D 공개 API 없음(확인한 대안·기관 명시)

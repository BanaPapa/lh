# 미확보 원천 전국 API 조사 (Grok, 2026-09-15)

조사 범위: data.go.kr · ODcloud · 레일포털(KRIC) · TAGO · LOCALDATA(1741000) · 나이스 · 대학알리미 · 문체부·소방·가스안전·화학물질안전원. 로컬 납품 파일은 후보에서 제외.

공통 인증 절차 (data.go.kr)
1. https://www.data.go.kr 회원가입
2. 데이터 상세 → **활용신청** (데이터셋마다 별도)
3. 마이페이지에서 일반 인증키 Encoding/Decoding
4. 개발단계 자동승인이면 수분~수시간 후 호출. 운영단계는 자동 또는 심의
5. 개발계정 일 트래픽: 보통 **10,000** (일부 1,000). 운영계정은 활용사례 등록 후 증량
6. ODcloud(`api.odcloud.kr`)는 같은 포털 키를 쓰되 **해당 파일데이터셋 활용신청**이 없으면 `{"code":-401}`

## 1. 소음진동배출시설 공장(라목) — **B** (50dB 예외 **C**)

**원천:** 전국소음진동배출시설표준데이터  
**기관:** 지방자치단체 취합 / 소관 기후에너지환경부  
**포털:** https://www.data.go.kr/data/15139233/standard.do  
**갱신:** 연간. 개별 지자체 파일을 월초 병합. 제공기관 46곳(2026-09 기준).

**엔드포인트 (확인, 프로젝트 실측 403):**
```
GET https://api.data.go.kr/openapi/tn_pubr_public_noise_vibration_emission_fclt_api
  ?serviceKey={키}&pageNo=1&numOfRows=1000&type=json
```
호스트는 `api.data.go.kr`(s 없음). 없는 경로는 400 `NO_OPENAPI_SERVICE_ERROR`, 미신청은 403 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`(코드 30).

**파라미터:** `serviceKey`(필), `pageNo`, `numOfRows`(최대 1000 관행), `type=json|xml`

**응답 필드 (그리드·전북 CSV 실측 확인):**

| 필드 | 내용 |
|---|---|
| fcltNm / 시설명 | 있음 |
| lctnRoadNmAddr, lctnLotnoAddr | 도로명·지번 |
| lat, lot | **WGS84 위경도** (예: 35.20915305, 129.1221524) |
| noisVbrtSeNm | 소음 / 진동 / 소음+진동 |
| noisVbrtMainCn | 설비 내용. 전북 원본은 전건 공란 |
| gnrlRgnYn, rdsdRgnYn | 일반·도로변 |
| dataCrtrYmd | 기준일 |
| 영업상태 | **없음** |
| 소음도 dB · 방음시설 | **없음** |

**전국:** 지자체 제출분 병합. 미제출 시군은 공백.

**인증:** 표준데이터 활용신청. 개발/운영 자동승인 관행, 개발 10,000. 현재 키 미등록 **403**.

**판단:** 위치 판정은 **B**. 라목 50dB 이하·방음 예외는 필드로 확인 불가 → 예외 미확인은 `review_required`가 정상. 예외 없다고 매입제외 확정하면 오판.

**확보 경로:** ① 포털 활용신청 → 어댑터 `noise_emission.py`는 코드 수정 없이 붙음 ② 50dB는 지자체 환경과 정보공개청구 또는 LH 수기 ③ 측정망 API는 측정소이지 공장 원장이 아님.

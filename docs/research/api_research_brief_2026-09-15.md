# 미확보 원천 전국 API 조사 브리프 (2026-09-15)

목적: LH 신축매입약정 서류심사 앱(`BanaPapa/lh`)은 **로컬 파일 없이 공개 API 만으로**
1차(매입제외 유해시설)·2차(생활편의성 배점)를 판정한다. 아래 항목은 아직 API 원천을
확보하지 못했거나(연결 필요) 심사표 지정 원천 대신 지도 검색으로 근사하고 있다.
각 항목에 대해 **전국 단위로 시설별 주소·좌표(또는 지오코딩 가능한 주소)를 주는
공개 API** 를 찾고, **키 발급·활용신청 절차까지** 구체적으로 적는다. 로컬 납품 파일·
사내 데이터셋은 대체 후보로 치지 않는다.

## 항목마다 보고할 것

1. 원천명 · 제공기관 · 포털 URL(data.go.kr 데이터 ID / ODcloud UDDI / 기관 자체 API 주소)
2. **실행 가능한 엔드포인트와 필수·선택 파라미터** (실호출 예시 URL, 응답 예시 필드)
3. 필드: 주소 유무 · 위경도 유무 · 좌표계(EPSG) · 시설유형/업태 구분 필드 · 영업상태 · 기준일 · 갱신주기
4. 전국 커버리지 여부(지역 한정이면 명시)
5. 인증: data.go.kr 일반 서비스키 / ODcloud 서비스키 / 기관 별도 신청 — **활용신청 화면 경로, 자동승인 여부, 승인 소요, 일일 트래픽 한도**
6. 판단: **A** 즉시 연결 가능 / **B** 활용신청·인증만 필요 / **C** 자료는 있으나 판정에 부족(좌표 없음·집계만·시설군 불일치) / **D** 공개 API 없음(확인한 대안·담당 기관·요청 방법 명시)
7. C·D 인 경우: 가장 현실적인 확보 경로(기관 정보공개청구, 파일 다운로드+지오코딩, 유료 API, 지자체 개별 API 묶기 등)를 순서대로.

가능하면 실제로 호출해 응답 스키마를 확인한다(키가 없으면 문서·샘플 응답으로). 추측 URL 은
「미검증」이라고 적는다. 이미 아는 것과 다른 결론이 나면 근거를 함께 적는다.

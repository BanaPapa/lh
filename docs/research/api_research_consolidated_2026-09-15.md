## 2. 지금 바로 할 일 (우선순위)

### 2-1. 활용신청 (코드 수정 없이 붙거나 어댑터만 추가)
공공데이터포털 로그인 → 각 데이터 상세 → 활용신청(개발계정 자동승인, 일 1,000~10,000):

1. CNG `15001508` (ODcloud) — 배선 완료, 승인만 하면 1차 CNG 25m 판정 시작
2. 소음진동 `15139233` — 등록공장 후보에 「소음배출 신고 있음」 주석
3. 철도역 `15067652` (ODcloud) — 2차 철도역 지정 원천
4. 도시공원 `15012890`, 전통시장 `15012894`, 초·중·고 `15021148`, 도서관 `15013109`, 환승센터 `15034541`
5. 문화시설 LOCALDATA 4종(`15154966`·`15154970`·`15155146`·`15154848`)
6. LPG 판매소 `15091481` (ODcloud) — 2024 기준일 고지 전제
7. 생활안전지도 `SAFEMAP_API_KEY` 재발급(현재 「등록되지 않은 키」) → 주유시설 IF_0033 + 화학물 IF_0049

### 2-2. 현재 키로 이미 되는 것 (배선)
- 버스 운행주기: TAGO `getRouteInfoIem.intervaltime` — 정류장 경유 노선 중 하나라도 ≤15분이면 인정, 값 없으면 「확인 불가」 고지
- 터미널: TAGO 고속·시외 터미널 목록 + 지오코딩(캐시)

## 3. 판정 원칙 재확인
원천이 없는 항목은 「주변 유해시설 없음」이 아니라 「판정 미적용·수기 확인」으로 남긴다(룰북 §3). 근사
원천(석유대체연료→도료, 카카오→지정 원천)은 근사임을 시설군마다 고지한다.

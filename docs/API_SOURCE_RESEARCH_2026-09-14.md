## 0. 한 줄 결론

**현재 「미연결」 16개 항목 중 8개는 전국 시설 단위 공개 API가 이미 존재하고, 막고 있는 것은 인증(활용신청·키 등록)과 어댑터 배선이다.** 나머지 8개는 두 도구 모두 전국 시설별 위치 API를 찾지 못했고, 집계·물질정보·지역 한정 자료만 있다. 이 8개는 기관 협의 또는 수기 확인 경로가 맞다.

두 도구 모두 실제 인증키로 호출하지는 않았다. 아래 `200·401·403`은 9/11 문서의 시험 결과다.

## 3. 기존 문서 정정 사항

- `HAZARD_SOURCE_MATRIX.md` #17 CNG의 「공개 API 없음」은 틀렸다. `15001508`에 위경도 포함 전국 자료와 ODcloud API가 있다. 룰북·`service.py`의 CNG 「CSV만」 주석도 함께 고쳐야 한다.
- 매트릭스의 「활용신청 승인만 남았고 코드 수정 불필요」는 단정할 수 없다. 401·403은 활용신청 미승인·키 전달 방식·인코딩·경로 변경이 섞일 수 있으므로 API별 실호출로 원인을 나눠야 한다.
- `docs/LH_CRITERIA_COVERAGE.md`(2026-08-29)는 테마파크·무도업·건축물대장을 「연결」로 적고 있어 매트릭스·브리프와 충돌한다. → **2026-09-14 확인: COVERAGE 가 맞다.** `facilities.db` `sync_state` 에 8개 데이터셋이 전부 적재돼 있고(테마파크 3종 335·무도장 35·무도학원 128·도시가스 68·고압가스 16,471·석유대체연료 719), 건축물대장 표제부 API 는 실호출 200(NORMAL SERVICE)이며 `_attach_building_register` 가 판정에 반영된다. 매트릭스에 정정 주석을 달았다.
- `backend/app/services/localdata.py` 어댑터는 좌표 없는 행을 버린다. 원천에 주소는 있으나 좌표가 빈 시설은 현재 적재에서 빠진다. 「주소 지오코딩으로 보완 가능」과 「현재 적재됨」은 같은 범위가 아니다.
- 9/11 문서의 「전남은 위험물 위치 공개」는 데이터셋별 컬럼을 다시 확인해야 한다. 이번에 확인한 광산소방서 자료는 시설명만 있고 주소가 없었다.

## 5. 이번 조사의 한계

- 인증키로 실호출하지 않았다. 「B」의 실제 해소 여부는 활용신청 승인 후 응답 스키마까지 확인해야 한다.
- LOCALDATA 사이트 직접 접근은 시간초과였고(Codex), 포털·개방 안내로 보완했다. 개별 업종 최신 명세는 미검증.
- 소방청·경찰청 본문 접근이 제한되어 「D」는 "이번 조사 범위에서 확인 못 함"이지 부존재 증명이 아니다.
- 원천 부재나 조회 실패를 「주변 유해시설 없음」으로 해석할 근거는 없다. 판정 미적용 항목은 계속 미적용으로 표시해야 한다.

## 원천 이원화 — 이 표를 읽는 기준

**제출본은 CSV 정본을 쓴다.** LH 내부망에서 외부 API 를 호출할 수 없으므로, 납품본의 판정 원천은
박진주 대표님 표준 데이터셋(`delivery/standardized/facilities.xlsx`)과 체크리스트가 지정한 원본 파일이다.
표의 **「원천(데이터셋)」 열이 제출본 기준**이다.

**제출 후 실운영은 API 직결로 전환한다.** 「원천(API)」 열은 그 전환 대상이자, 지금 이 앱이
교차검증 도구로서 CSV 정본의 누락·오류를 잡는 데 쓰는 경로다. 두 원천이 같은 시설을 다르게
보고하면 그 차이 자체가 검증 결과다.

**따라서 원천이 다른 것은 결함이 아니라 설계다.** 예를 들어 주유소는 제출본이 산업통상부
전국 주유소 등록현황 CSV 를 쓰고, 이 앱은 생활안전지도 `IF_0033` 로 독립 조회한다.
대조 시 두 열을 함께 봐야 한다.

## 연결여부 값의 뜻

| 값 | 뜻 |
|---|---|
| **연결** | 앱이 실제로 조회해 판정에 쓰고 있다 (적재·직결·배선 완료) |
| **모듈 완성·미배선** | 어댑터는 완성됐으나 좌표(지오코딩) 또는 추가 원천이 없어 이번 배선에서 빠졌다 |
| **대체** | 심사표 지정 원천이 아닌 카카오 지도로 근사하고 있다. 값이 지정 원천과 다를 수 있다 |
| **미확보** | 공개 원천을 찾지 못했다. 신청·구매로 해결되지 않는다 |
| **판정 제외** | 협의로 자동 판정 집계에서 제외 |

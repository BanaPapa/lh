변경 이력 표시: 주황색 = v1.2 → v1.3 변경 · 보라색 = v1.3 → v1.4 변경. 최신 LH 최종 정정회신은 보라색으로 표시한다.

항목기준

5. 공장 판정 Rule

공장등록 = 유해공장 아님. 법령 가~라 중 해당 항목의 AND 조건이 모두 확인된 공장만 판정대상으로 사용한다.
목판정조건박진주 데이터 원천데이터 상태현재 처리
가특정대기유해물질 배출 AND 공장현재 적합 공개 원천 미확보미확보판정 미적용 · 별도 수기 확인 — LH 요청2 승인
나대기오염물질배출시설 설치 AND 1~3종 AND 공장행안부 대기오염물질배출시설설치사업장 + factoryON 등록공장승인AND 매칭 성립 건을 판정대상으로 사용 — LH 요청1 승인
다4~5종 AND 국토부 고시업종 AND 공장대기배출시설 + factoryON + 국토부 고시 업종목록승인AND 매칭 성립 건을 판정대상으로 사용 — LH 요청1 승인
라소음배출시설 설치 AND 공장전국소음진동배출시설표준데이터 + factoryON승인AND 매칭 성립 건을 판정대상으로 사용. 50dB/방음시설 예외 미확인 시 REVIEW_REQUIRED — LH 요청1 승인
매칭키공장 원천 간 동일시설 매칭은 지번 문자열보다 PNU를 우선키로 사용한다. PNU 불일치·결측 시 임의 문자열 유사매칭으로 확정하지 않는다.

6. 데이터 표준화 전제 [v1.3 추가]

순서처리판정 전 기준
①좌표계 변환투영좌표 원천은 원좌표계를 확인한 뒤 WGS84로 변환하고 변환 후 전북 범위 재검사.
②지오코딩 / 위치보완좌표 결측 행은 지번주소·도로명주소·PNU를 이용해 위치 보완. 실패 행은 삭제하지 않고 격리.
③운영상태 필터폐업·취소·말소는 판정 투입 전 제외. 휴업 및 상태 공란 처리기준은 아직 확정하지 않으며 확인대기로 관리.
④중복 처리판정근거 원천을 보존한다. 특히 공장 가~라 AND 매칭에 필요한 서로 다른 원천 레코드는 중복으로 삭제하지 않는다.
⑤오류행 격리보완 실패·주소 결측 등은 삭제하지 않고 사유와 함께 별도 관리. 자동판정에는 사용하지 않음.

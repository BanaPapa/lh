## 저장소에 두지 않는 것

**카카오톡 대화내역 원본은 저장소에 포함하지 않는다.** 주민등록번호 앞자리, 개인 이메일,
계약금액 등 판정과 무관한 개인정보가 섞여 있고 git 히스토리는 되돌리기 어렵기 때문이다.
